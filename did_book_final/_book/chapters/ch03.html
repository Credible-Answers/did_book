1.1 Overview

Dataset: Moser & Voena (2012) — moser_voena_didtextbook.dta

The Trading with the Enemy Act (TWEA) allowed US firms to use German-owned patents. Treatment (\(D_{g,t}\)) equals 1 for the 336 subclasses that received German patents, starting in 1919. The dataset contains 289,920 observations (7,248 subclasses × 40 years).

1.7 Green Question 6: Linear Pre-Trends We Could Fail to Detect

Use the pretrends package (Roth, 2022) to compute the slope detectable with 50% power using 6 pre-periods.

  • Python

library(pretrends)
# Extract coefficients and vcov for first 6 pre-periods
pretrend_coefs_6 <- paste0("reltimeminus", 1:6)
beta <- coef(model6)[pretrend_coefs_6]
sigma <- vcov(model6)[pretrend_coefs_6, pretrend_coefs_6]
slope50 <- slope_for_power(sigma = sigma, targetPower = 0.5,
                           tVec = -6:-1, referencePeriod = 0)
cat("Slope for 50% power:", slope50)
Slope for 50% power (numpre=6): 0.009796021
from scipy import optimize

short_minus = [f"reltimeminus{i}" for i in range(1, 7)]
fml_pre = "patents ~ " + " + ".join(short_minus + plus_vars) + " | treatmentgroup + year"
m6 = pf.feols(fml_pre, data=df, vcov={"CRV1": "subclass"})
coefs_pre = m6.coef()
vcov_pre = pd.DataFrame(m6._vcov, index=coefs_pre.index, columns=coefs_pre.index)
pre6 = [v for v in short_minus if v in coefs_pre.index]
V_pre6 = vcov_pre.loc[pre6, pre6].values
n_pre = len(pre6); dfd = df["subclass"].nunique() - 1

def power_at_slope(slope):
    mu = np.array([slope * (-int(v.replace("reltimeminus", ""))) for v in pre6])
    ncp = mu @ np.linalg.inv(V_pre6) @ mu
    cv = stats.f.ppf(0.95, n_pre, dfd)
    return 1 - stats.ncf.cdf(cv, n_pre, dfd, ncp)

slope_50 = optimize.brentq(lambda s: power_at_slope(s) - 0.5, 0.0001, 1.0)
print(f"Slope for 50% power (numpre=6): {slope_50:.6f}")
Slope for 50% power (numpre=6): 0.008878

Note: Stata and R use the official pretrends package (Roth 2022) and give ≈0.0098. Python uses a manual F-test-based implementation and gives ≈0.0089. The difference is due to the underlying distributional assumptions (multivariate normal vs. non-central F).
